Learning resources beyond the 2026 course content. They're recommended by the course's
[*Further learning*](https://www.ebi.ac.uk/training/materials/data-science-for-life-scientists-materials-2026/further-learning/) page.

| Folder / resource | What it is |
|-------------------|------------|
| [`2025_edition/`](2025_edition/) | Index of the **2025 edition** (statistics, Cytoscape network analysis, FAIR data, ethics, green computing, …). Downloaded locally with `make fetch-2025`; nothing committed |
| [Further learning list](../COURSE_MATERIALS.md#-further-learning) | EMBL-EBI tutorials and webinars recommended after the course (links only) |
